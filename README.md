# Bingwa-Sokoni-Applicaton
Automate your Bingwa Sokoni services for seemless and efficient recommendation of your offers.

# Instructions on How To Use
1. Download the APK file above.
2. Install the APK to your phone.
3. Ensure you Notification Sim Card that receives the payment notifications is available in the phone.
4. Select the Sim Card to use. (The Notification number sim card).
5. Ensure it has airtime.
6. Go to settings page and edit the data plans to match your offers.
7. Go to notifications page to customize the messages that will be sent to the customer and also choose which Sim to send sms with then save the changes.
8. Ensure you have Sms to be able to send sms messages.
9. You are all done 👌😊👏👏
